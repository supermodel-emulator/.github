# Supermodel - Sega Model 3 Arcade Boards

![Supermodel attract mode with arcade controls mapped](https://i.ytimg.com/vi/lCxak8bG7zk/maxresdefault.jpg)

## At a Glance

Supermodel is aimed at one arcade generation. The games that ran on Model 3 hardware can be driven from a PC if you have a dump the emulator can parse and a machine with enough GPU and CPU. Controls are an arcade panel in spirit: steering, gears, guns, or buttons, depending on the title. A generic gamepad works after you map the inputs that title actually used.

- A ROM set the version of Supermodel documents
- A config per game when the inputs differ
- Full screen only after the game reaches its attract mode
- No other Sega generations included
- No ROMs shipped with the emulator

If you do not have a legal dump, stop. Supermodel is not a source of arcade games.

Video options that raise resolution come after the attract mode is stable. A black screen is not a resolution problem until a known-good set has booted at defaults.

## Steps

1. Read which ROM layout this Supermodel build wants.
2. Point it at one set you may use.
3. Map coins, start, and the main controls.
4. Reach attract mode before you change rendering.
5. Save that game's config under its name.
6. Do not copy that control map onto a driving game without looking.

## Fits

Model 3 arcade software you may run, on a PC that can hold the frame rate. A poor fit for Saturn, Naomi, or a console ROM. A poor fit for a laptop that throttles as soon as the GPU wakes. A poor fit as a place to complete a ROM set from the internet.

## Fixes

The game will not start. The set is incomplete or for another emulator version.
Controls do nothing. Coin and start were never mapped.
The picture is a smear. Return to default rendering.
Audio stutters. Lower the extra effects and close background GPU apps.
Another Sega game was dragged in. It is the wrong hardware. Use the emulator that matches that board.

## Attract Mode, Then the Controls That Game Used

Supermodel should reach attract mode on a complete Model 3 set this version expects, with rendering left at the default. Coin and start have to be mapped or the game looks dead. A racer needs gears and pedals. A gun game needs the axis the build expects. Copying a fighter layout onto a driving game is a new config, not a small tweak. Save the map under the game's name.

Video upgrades wait until attract mode is stable. A black screen is not a resolution problem until a known-good set has booted. Other Sega generations will not run. Incomplete zips will not become a game because the emulator started. You supply a set you may use. The emulator does not.

- ROM layout matches this build
- Coin and start mapped
- Per-game config saved
- Default video first
- Service and test switches available
- Saturn and Dreamcast excluded
- A desktop GPU, not a throttled laptop, if the frame rate falls
